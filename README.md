# TURA Apps

Веб-приложения TURA для пациентов домашней нейрореабилитации (Астана).
Публикуются через GitHub Pages: https://nauryzbay-tura.github.io/Tura-apps/

| Приложение | Папка | Описание |
|---|---|---|
| VOR×1 — тренажёр стабилизации взора | `vor1/` | Упражнение для пациентов с головокружением и нистагмом после инсульта: метроном, назначение специалиста, оценка головокружения, автопрогрессия, дневник и отчёт. Камера (β): скорость и размах поворотов головы, удержание взгляда, поправочные саккады, тест стабилизации взора. |
| Неглект — тренажёр пространственного внимания | `neglect/` | Оценка (тест вычёркивания с расчётом CoC и картой поиска, шкала CBS куратора и пациента), план занятия по разнице CBS, плавное слежение, сканирование с адаптивным якорем, поиск предметов комнаты пациента по фото (якорь, гироскоп, подсказки по нарастающей, режим нагрудного крепления со звуком), бдительность (go/no-go), дневник семьи, отправка в Google Sheets через Apps Script. Камера (β): контроль поворота головы. |

| TURA Motion — оценка и тренировка движений | `motion/` | Камерная оценка и тренировка после инсульта. Режим инструктора: 5 вставаний со стула (5xSTS), «Встань и иди» (TUG) с фазами, секундомер ходьбы 10 м, эталон руки дня 1; сохранение как день 1 / день 10 и отчёт «до/после» с текстом для CRM. Режим пациента: 5 упражнений (подъём и отведение руки, сгибание локтя, вставание, подъём колена сидя) со счётчиком повторов, сигналом «засчитано» и одной подсказкой после подхода; компенсации (наклон корпуса, подъём плеча, согнутый локоть, неполная амплитуда) считаются от исходной позы пациента. Источники: живая камера, запись видео, демо без камеры. Доза по дням для куратора. (β) |

Данные пациентов хранятся только в браузере телефона (localStorage) и не попадают в репозиторий.
VOR×1 устанавливается как приложение (PWA: manifest + service worker `vor1/sw.js`), работает без интернета после первой загрузки; назначение передаётся ссылкой или QR-кодом (`#rx=…`, без сервера), раздел специалиста защищается PIN. QR-коды: qrcode-generator 2.0.4 (MIT, Kazuhiko Arase), `vor1/qrcode.js`.
Приложения выполняются по назначению специалиста TURA и не заменяют консультацию врача.

Камера: MediaPipe Face Landmarker (@mediapipe/tasks-vision 1.2.3) работает в браузере на устройстве; видео не отправляется и не сохраняется. Метрики взгляда экспериментальные (β) и требуют проверки на реальных пациентах.
TURA Motion использует MediaPipe Pose Landmarker (lite, @mediapipe/tasks-vision 1.2.3) так же — на устройстве, хранятся только итоговые числа. Пороги счёта и компенсаций стартовые (β) и требуют калибровки на пациентах TURA.
