# TURA Apps

Веб-приложения TURA для пациентов домашней нейрореабилитации (Астана).
Публикуются через GitHub Pages: https://nauryzbay-tura.github.io/Tura-apps/

| Приложение | Папка | Описание |
|---|---|---|
| VOR×1 — тренажёр стабилизации взора | `vor1/` | Упражнение для пациентов с головокружением и нистагмом после инсульта: метроном, назначение специалиста, оценка головокружения, автопрогрессия, дневник и отчёт. Камера (β): скорость и размах поворотов головы, удержание взгляда, поправочные саккады, тест стабилизации взора. |
| Неглект — тренажёр пространственного внимания | `neglect/` | Оценка (тест вычёркивания с расчётом CoC и картой поиска, шкала CBS куратора и пациента), план занятия по разнице CBS, плавное слежение, сканирование с адаптивным якорем, поиск предметов комнаты пациента по фото (якорь, гироскоп, подсказки по нарастающей, режим нагрудного крепления со звуком), бдительность (go/no-go), дневник семьи, отправка в Google Sheets через Apps Script. Камера (β): контроль поворота головы. |

| TURA Motion — оценка и тренировка движений | `motion/` | Камерная оценка и тренировка после инсульта. Режим инструктора: 5 вставаний со стула (5xSTS), «Встань и иди» (TUG) с фазами, секундомер ходьбы 10 м, эталон руки дня 1; сохранение как день 1 / день 10 и отчёт «до/после» с текстом для CRM. Режим пациента: 5 упражнений (подъём и отведение руки, сгибание локтя, вставание, подъём колена сидя) со счётчиком повторов, сигналом «засчитано» и одной подсказкой после подхода; компенсации (наклон корпуса, подъём плеча, согнутый локоть, неполная амплитуда) считаются от исходной позы пациента. Источники: живая камера, запись видео, демо без камеры. Доза по дням для куратора. Игры с обратной связью: «Фрукты» (дотягивание рукой, в духе Fruit Ninja), «Шары» (подъём прямой руки с удержанием), «Ракета» (вставание со стула), «Лодка» (перенос веса корпуса сидя); очки только за движение без компенсаций, уровень подстраивается под пациента. (β) |
| TURA Кисть — игры для кисти | `hand/` | Отдельный модуль к TURA Motion на MediaPipe Hand Landmarker (21 точка кисти). «Яблоки»: сжать кулак над яблоком, перенести и раскрыть ладонь над корзиной; яблоко падает, только если кисть раскрыта до цели. «Ягоды»: щипок большим и указательным, затем средним, безымянным и мизинцем; ягода, взятая всей кистью, мнётся. «Пианино»: сгибание пальца своей дорожки, чистое нажатие (соседние пальцы неподвижны) даёт полные очки. «Машинка»: предплечье и ладонь на столе, под нужный палец подъезжает машинка; сначала калибровка пальца (дважды поднять как можно выше — это 5-й этаж), затем подъём ведёт машинку по линейке до заданного этажа, удержание паркует; остальные пальцы должны лежать на столе. Подъём меряется двумя способами (угол над плоскостью ладони и смещение кончика на изображении), вес каждого — по отношению размаха к шуму покоя. Играет только поражённая кисть (по выбранной стороне); перед игрой с камерой — проверка кадра (нужная рука, вся кисть в кадре, размер, направление пальцев). Цели раскрытия, сжатия, щипка и сгибания каждого пальца подстраиваются под пациента. Пациенты и доза общие с Motion (одно хранилище в браузере), раунды попадают в отчёт Motion. (β) |

Данные пациентов хранятся только в браузере телефона (localStorage) и не попадают в репозиторий.
VOR×1 устанавливается как приложение (PWA: manifest + service worker `vor1/sw.js`), работает без интернета после первой загрузки; назначение передаётся ссылкой или QR-кодом (`#rx=…`, без сервера), раздел специалиста защищается PIN. QR-коды: qrcode-generator 2.0.4 (MIT, Kazuhiko Arase), `vor1/qrcode.js`.
Приложения выполняются по назначению специалиста TURA и не заменяют консультацию врача.

Камера: MediaPipe Face Landmarker (@mediapipe/tasks-vision 1.2.3) работает в браузере на устройстве; видео не отправляется и не сохраняется. Метрики взгляда экспериментальные (β) и требуют проверки на реальных пациентах.
TURA Motion использует MediaPipe Pose Landmarker (lite, @mediapipe/tasks-vision 1.2.3) так же — на устройстве, хранятся только итоговые числа. TURA Кисть использует MediaPipe Hand Landmarker (float16, та же библиотека) тем же способом. Пороги счёта и компенсаций стартовые (β) и требуют калибровки на пациентах TURA.
